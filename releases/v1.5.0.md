# Stream overlay and floating tracked items

- New **Stream & floating list** tab with a live preview of your active operator’s supply list.
- Open a movable, resizable floating window. **Keep on top** is optional, and the app remembers the window’s position and size.
- Connect the Windows app directly to an OBS Browser Source on the same PC. Enable the overlay and copy its local link; no plug-in or cloud account is needed.
- Item icons, remaining counts, stash progress, and optional cash requirements update as your tracker changes, including cloud-synced edits.
- Adjust text size, background opacity, missing-only filtering, and rows per stream page. Longer lists can rotate automatically. The floating window scrolls through the complete list.
- The overlay excludes account details and operator names. It shows a reconnect message if the tracker closes or the connection is disabled.
- The website also has a floating list; keep its original tracker tab open.

In OBS, start with a 420 × 900 Browser Source. Increase the height for more rows or larger text, then position and scale it in your scene. The Windows app must stay open or minimized. Borderless/windowed game mode works best with the floating window.

Progress and sign-in are preserved. Installed version 1.4.0 can download this release internally using **Update now**, then **Restart & update**. Older portable versions need the installer once.

The official game API is not connected. These views use your tracker progress; they do not read the game.
