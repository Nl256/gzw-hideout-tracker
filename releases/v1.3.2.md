## Bugs, suggestions, and replies

- New **Feedback** tab in the website and Windows app.
- Separate **Report a bug** and **Suggest an improvement** forms on GitHub.
- **View all feedback** lets you browse conversations, add comments, and follow replies from the maintainer.
- Forms include the tracker version, app type, and catalogue date. Saved progress is never attached automatically.

A free GitHub account is needed to post or reply. Feedback is public; leave out personal information and save backups.

Download **GZW-Hideout-Tracker-Windows-x64.exe** and double-click it on a 64-bit Windows PC. Everything is included; no installation or extra software is needed. The app is not code-signed, so Windows may show an unknown-publisher notice.

Your existing PC progress and optional GitHub cloud saves are preserved. Catalogue corrections continue to arrive automatically. Install this version by replacing your old EXE to get the new Feedback tab.
