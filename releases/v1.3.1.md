The portable Windows edition of the GZW 0.5 Hideout Operations Desk.

- Optional GitHub sign-in shares your cloud save with the website.
- Guest progress saves locally without an account.
- Material counts and built tiers save automatically. Changing a built tier no longer opens an Update progress popup.
- Published hideout catalogue corrections download automatically, with offline support.
- Includes item icons, upgrade planning, stash tracking, backups, and Undo.

Download **GZW-Hideout-Tracker-Windows-x64.exe** below and run it on 64-bit Windows. No installer is required. The app is not code-signed, so Windows may show an unknown-publisher warning.

Existing users keep their local progress when switching to this EXE. Use the same GitHub account as the website to share cloud progress. Guest saves on different devices stay separate; use Backups to transfer them.

The accompanying `.sha256` file is the download checksum. Catalogue updates arrive automatically; application updates require downloading the latest EXE.
