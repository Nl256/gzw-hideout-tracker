The Windows app now offers app updates inside the tracker. When a newer release is available, choose **Update now** or **Later**. Download progress appears in the app; choose **Restart & update** when ready. There is no browser download or manual file replacement for later updates.

- Checks on launch, when returning to the app, and periodically while open.
- A **Check for app updates** button is available at the bottom of the window.
- Material and upgrade-list corrections still arrive automatically without a prompt.
- Interrupted or unverified downloads leave the current app available. Saved progress stays in the same location.

**One-time setup for existing users:** close the old app and run **GZW-Hideout-Tracker-Windows-x64.exe** to install this updater-enabled version, then use its desktop shortcut instead of the old portable EXE. Existing PC progress and sign-in are kept. It installs for your Windows account and needs no extra software or administrator rights. Older portable EXEs cannot update themselves to this version.

The app remains unsigned. App updates come from this repository’s published Windows releases and are checked against the release checksum.
